# BeSmart Studio（BSS）— スマホで作れるBMS制作ツール

スマートフォンのブラウザだけで、BMSの譜面を作ったり、今あるBMSを編集したりできる制作ツールです。インストールも登録も要りません。

- **使う**：https://u1908inter.github.io/besmart-studio/
- **紹介・操作方法**：https://u1908inter.github.io/besmart-studio/about.html
- **遊ぶ（BMSプレイヤー BeSmart）**：https://u1908inter.github.io/besmart/

## できること

- タップでノーツを置く・選ぶ・消す、長押し（PCはドラッグ）で移動・コピー
- ロングノーツ、BPM変更、一時停止（STOP）、変拍子（n/m）
- BGA（画像・動画）の配置、選曲画面の画像の設定
- 今あるBMSを開いて編集（書庫：ZIP・LZH・RAR・7z）
- ZIPで保存して、BeSmartなどのBMSプレイヤーで遊ぶ
- オフライン対応（ホーム画面に追加すると、BeSmartとは別のアプリとして起動できます）

RAR・7zの展開には、BeSmart本体（u1908inter/besmart）と同じ部品（libarchive.js・node-unrar-js）を使っています。ライセンスは `licenses/` とアプリの「設定」タブにあります。
